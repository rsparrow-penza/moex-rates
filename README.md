# 📊 MOEX Rates — курсы USD, EUR и CNY с Московской биржи

Второй учебный проект: сервис, который **сам, раз в час**, читает курсы валют
с публичного API ММВБ (ISS), сохраняет их в базу SQLite, а веб-страница
показывает историю с выбором диапазона дат и графиком.

## Структура страницы: шесть вкладок

| Вкладка | Hash | Что внутри | Чей источник |
|---|---|---|---|
| 💱 Курсы валют | `#/fx` (по умолчанию) | фильтры, график курсов, дневная таблица | ММВБ, Yahoo, CoinGecko |
| 🏦 ЦБ: ставка, прогноз, банки | `#/cbr` | ключевая ставка + RUONIA, календарь заседаний, среднесрочный прогноз, топ-10 и избранные банки | ЦБ, указатель ЦБ |
| 📈 Экономика | `#/econ` | инфляция, ставки по кредитам и вкладам, реальный сектор, федеральный бюджет | ЦБ, World Bank, Росстат, Минфин (вручную) |
| 🪙 Металлы | `#/metals` | GOLD/SILV/PLT/PLD ($/унция) + COPPER/ALUM ($/тонна): ФОРТС, мир, базис, ₽; ниже — металлопрокат в ₽/т | ММВБ ФОРТС, COMEX/NYMEX/LME, Росстат, «Металлоснабжение и сбыт» |
| 🧱 ОФЗ | `#/ofz` | живой борт всех ОФЗ + кривая по фиксированной корзине | ММВБ, борт TQOB |
| 🏞 Пензенская область | `#/penza` | инфляция, цены по 18 позициям, жильё, доходы, выпуск | Росстат (выгрузки по субъектам) |

Маршрут — хеш (`#/changelog` живёт рядом, библиотека не нужна: адресов
семь, хватает `hashchange`). Данные каждой вкладки грузятся только когда
она открыта, поэтому переход между вкладками не превращается в пачку
запросов на старте. Ссылки вида `#/econ` можно расшаривать — они ведут прямо к нужной
теме.

## Стек

| Слой | Технологии |

## Источники данных (это интересная часть)

- **USD**: `USDFIXME` — валютный фиксинг МосБиржи. Биржевые спот-торги
  долларом приостановлены, поэтому берём биржевой фиксинг; он обновляется
  раз в сутки (~13:00 МСК).
- **USD·OTC**: Yahoo Finance (`RUB=X`) — **внебиржевой межбанковский курс**,
  он же в приложении «Акции» на iPhone. Обновляется круглосуточно;
  забирается внутридневной ряд с шагом ~15 минут за последние сутки.
  ⚠️ Неофициальный API: может измениться или исчезнуть — поэтому это
  второй источник, а не замена ММВБ.
- **EUR**: `EURFIXME` — то же для евро: фиксинг МосБиржи, раз в сутки.
- **EUR·OTC**: Yahoo Finance (`EURRUB=X`) — межбанк по евро, те же сутки
  с шагом ~15 минут.
- **CNY**: `CNYRUB_TOM` — полноценные спот-торги юань/рубль, цена
  обновляется весь торговый день (10:00–23:50 МСК).
- **USD/EUR/CNY ·ЦБ**: официальный курс ЦБ РФ прямо с cbr.ru
  (`XML_daily.asp`): один XML на все валюты сразу, кодировка windows-1251,
  даты «дд.мм.гггг», разделитель-запятая в числе. Работает и для выходных.
- **Топ-10 и избранные банки**: отчётность одного банка по РСБУ, которую ЦБ
  выкладывает в разделе «Информация по кредитным организациям → Формы
  отчётности»: оборотная ведомость 0409101 (активы нетто, вклады физлиц —
  сумма 42.2 + 522, средства юрлиц — 401–407/410–422/427–439 + 521, прибыль
  по счёту 706), расчёт капитала 0409123 (строка 000) и нормативы 0409135
  (Н1.0). Живого API у раздела нет, поэтому срез лежит в базе и обновляется
  вручную (см. «Обновление рейтинга банков»); формулы — те же, что у
  рейтинга Банки.ру. Это не МСФО: у банка без «дочек» цифры меньше
  групповых, а ПСБ форму 0409101 не публикует вовсе (активов, вкладов и
  средств организаций у него нет — на фронте прочерк).
- **Металлы (ФОРТС + мир)**: фьючерсы MOEX `GOLD/SILV/PLT/PLD` (ISS, CLOSE) и
  COMEX/NYMEX через Yahoo (`GC=F`, `SI=F`, `PL=F`, `PA=F`) — $ за тройскую
  унцию; ближайший контракт подбирается автоматически (см. «Металлы на бирже»).
- **Пензенская область**: сайт Пензастата снаружи недоступен (см. раздел
  «Пензенская область»), поэтому регион берётся из федеральных выгрузок Росстата
  по субъектам: `ipc_RF_fo_sub_*` (ИПЦ по месяцам, лист на каждый месяц с 2022),
  `sred_potreb_cen_*` (цены по позициям), `IVBO_sub_RF_*` (индекс выпуска),
  `sred_cen_perv/vtor_*` (жильё), `urov_10subg/11subg_*` (доходы).
- **Металлопрокат**: два ряда в одном блоке — официальные средние цены
  производителей Росстата (`Proizvoditeli_Cena_MM-YYYY.xlsx`, ₽ за тонну, по РФ,
  месячные) и мониторинг журнала «Металлоснабжение и сбыт» (дилерские цены
  Москвы, ₽ за тонну, раз ~в две недели). Биржевого проката нет: на ФОРТС из 536
  контрактов металлургических ноль, движок `commodity` — это НТБ (нефть, кокс,
  зерно); СПбМТСБ снаружи отдаёт только антибот-оболочку, fedstat — 403.
- **Bitcoin**: CoinGecko — `simple/price` (живая цена в ₽, крипторынок
  работает 24/7) и `market_chart` (дневная история за 90 дней) для backfill.
- **Нефть Brent**: Yahoo Finance (`BZ=F`) — дневные закрытия фьючерса в $
  (backfill за 90 дней) плюс внутридневные 15-минутки, как у OTC-валют.
  В таблицу Brent и Gold попадают ДНЕВНЫМИ строками (rate_time пусто) и в $;
  внутридневные тики и Bitcoin (часовые точки 24/7) остаются только на графике.
- **Золото**: Yahoo Finance (`GC=F`) — мировая цена, $ за тройскую унцию
  (ISS-металлы снаружи недоступны); тот же режим: сутки+история, график.
- **RUONIA**: средняя ставка однодневных межбанковских кредитов — со
  страницы cbr.ru (`hd_base/ruonia/`); источник отдаёт только последние
  дни, поэтому дневной ряд копится у нас с каждым часовым обходом и
  рисуется бирюзовой линией поверх ступенек ключевой ставки.
- **Годовая инфляция**: открытый JSON Всемирного банка (агрегированный
  Росстат, ИПЦ % к предыдущему году) — ряд с 1993 года, обновление раз
  в год; на странице логарифмические столбики, иначе 1993-й (874%)
  сплющил бы всё остальное.
- **Прогноз ЦБ**: справочный блок с траекторией ключевой ставки и
  инфляцией по трём сценариям (цифры из среднесрочного прогноза,
  обновляются после опорных заседаний).

У каждой записи в базе есть `source` (MOEX/YAHOO/CBR) и `rate_time` —
внутридневные точки OTC живут рядом с дневными, не мешая им.

График умеет два режима (переключатель **% / ₽**):
- **%** — изменение каждой валюты от начала периода на общей шкале:
  ряды 12/81/90 ₽ сравнимы, видно, кто за период сильнее вырос или упал.
  Пунктир — официальные курсы ЦБ, сплошные линии — биржа и OTC.
- **₽** — абсолютные цены: у каждой валюты своя мини-полоска со своей
  шкалой (приём «small multiples»), чтобы юань не сплющивало у нуля.

Абсолютные значения — и в таблице: ММВБ и ЦБ стоят бок о бок, есть
что сравнить (OTC в таблицу не попадает — сутки 15-минуток раздули бы её);
Brent и Gold — отдельными колонками в $, выходные и биржевые праздники
отмечаются прочерком.

Плюс «backfill»: при первом запуске подтягивается история за ~90 дней,
чтобы таблица сразу была не пустой.

## Блок «Металлы на бирже»

Цены драгметаллов берутся с двух площадок и в одних единицах — $ за тройскую
унцию:

* **ФОРТС (MOEX)** — ближайшие контракты `GOLD` (золото), `SILV` (серебро),
  `PLT` (платина), `PLD` (палладий). Дневной ряд — `CLOSE` поhistory ISS:
  `history/engines/futures/markets/forts/securities/<SECID>.json` (ISS режет
  выдачу по 100 строк — обход страницами через `start=`).
* **Мир** — те же металлы через Yahoo: `GC=F`, `SI=F` (COMEX) и `PL=F`,
  `PA=F` (NYMEX), тот же chart-endpoint, что качает Brent.

Контракт квартальный: `pick_forts_contract()` каждый раз выбирает ближайший
не истёкший по `LASTTRADEDATE` и запоминает выбор в `metal_contract`. Когда
`GDZ6` переедет, ряд продолжится следующим контрактом — в месте переклейки
возможен скачок на величину контанго (это не ошибка данных).

Спот-котировки ГЦМ ММВБ (слитки) публичный ISS не отдаёт — поэтому фьючерсы.
Производные: **базис** (ФОРТС / мир − 1, %) и **₽/грамм** (цена × курс ЦБ
доллара / 31,1034768). API: `GET /api/metals`.

## Рынок ОФЗ: живой борт + фиксированная корзина

Два разных права на состав — и оба честные:

| Что | Источник | Состав |
|---|---|---|
| Таблица «Все ОФЗ на бирже» | `ofz_board` ← один запрос к борту TQOB (`securities.json` + `marketdata.json`) | **весь борт**: 61 выпуск на 27.11.2026 (34 ПД, 21 ПК, 4 ИН, 2 АД). Новый выпуск появляется сам, в тот же день |
| Кривая и её наклон, график «как менялись доходности» | `ofz_snapshot` + `econ_series` по `OFZ_UNIVERSE` | 13 выпусков ПД, правится руками |

Клик по строке таблицы добавляет выпуск на график. Если ряда нет в базе, фронт
просит `GET /api/ofz/series?secid=…` — бэкенд качает `YIELDCLOSE` с биржи
(страницами по 100) и кладёт в ту же `econ_series`, при повторном клике отдаёт
из базы, пока данные не старше трёх дней. SECID проверяется по борту: произвольная
строка не должна превращать сервис в прокси к ММВБ.

Тип выпуска берётся из `LATNAME` (`OFZ-PD` → ПД). У ПК биржа доходность не
рассчитывает (в выдаче 0) — в таблице прочерк, и в `ofz_board` он хранится как
NULL, а не как ноль: иначе средний по колонке стал бы выдумкой.

**Охранение по сессии.** `_ofz_session_open()` (10:30–23:30 МСК) проверяют и
`fetch_ofz_snapshot()`, и `fetch_ofz_board()`: до открытия секции борт отдаёт
вчерашние доходности с пустой ценой и нулевым оборотом, и «сегодняшний снимок»,
записанный в 7 утра, затирал бы вчерашний настоящий. Поэтому ночные и ранние
прогоны (в том числе сид) просто ничего не пишут, а фронт показывает последний
честный день. Даты снимков — по МСК, а не по UTC контейнера.

## Пензенская область

Региональный разрез тех же федеральных сюжетов. Собственный сайт территориального
органа не открывается: `58.rosstat.gov.ru` резолвится в `194.226.89.60`, но TCP
молчит и на 80, и на 443 — с локальной машины и с VPS, `nc` тоже;
`pensastat.gks.ru` не резолвится (проверено 27.11.2026). Территориальный орган
сдаёт те же наблюдения в Росстат, а Росстат публикует их файлами по субъектам —
это тот же первоисточник, только доступный.

| Сюжет | Файл | Ряды |
|---|---|---|
| Инфляция | `ipc_RF_fo_sub_MM-YYYY.xlsx` | `rf_*`, `pfo_*`, `region_*`: mom (из файла) и yoy (произведение 12 месяцев, считаем сами) |
| Цены по позициям | `sred_potreb_cen_MM-YYYY.xlsx` (15–17 МБ) | `rfg_*`, `pzg_*`, `pzc_*` по 18 позициям |
| Выпуск товаров и услуг | `IVBO_sub_RF_MM-YYYY.xlsx` | `region_output_yoy`, `pfo_output_yoy` |
| Жильё, ₽/м² | `sred_cen_perv_Nkv-YYYY.xlsx`, `sred_cen_vtor_Nkv-YYYY.xlsx` | `region_*`, `city_*`, `rf_*` |
| Доходы | `urov_10subg_NkvYYYY_yt.xlsx`, `urov_11subg_NkvYYYY_yt.xlsx` | `region_income_sdd`, `rf_income_sdd`, `..._rdd` |

Что нужно знать при правке (всё это поймано на живых файлах):

- **Коды территорий отличаются между файлами**: в ИПЦ — укороченные (`56000000`),
  в ценах и жилье — полные ОКАТО (`56000000000`), а город Пенза идёт отдельной
  строкой (`56401000000`) сразу за областью.
- **Подписи компонентов ИПЦ лежат на строку ниже заголовка** («в том числе:» →
  продовольственные / непродовольственные / услуги). Искали их в строке
  заголовка — плитки оставались пустыми при полных данных в базе.
- **Лист центра субъекта называется именем области**, но цифры в нём относятся к
  областному центру. Проверка «по центру» против «в целом» ловила перепутанные
  местами значения.
- **Ссылки на прошлые годы битые**: на странице висят `sred_cen_vtor_4kv-2025.xlsx`
  и т.п., но отдают 404 по всем. Значит, резолвер обязан брать первый реально
  скачавшийся файл (подпись `PK`), а не первый в списке, и глубина ряда по ценам
  и жилью растёт только у нас в базе.
- **Годового архива цен по субъектам нет**: `sred_potreb_cen_1991-2025.xlsx` —
  это средние по России, строк региона в файле нет.
- **Часть городских цен закрыта `…`** (например, бензин) — это прочерк, а не ноль;
  `…` в числах вообще разбирает `_rub_number`.
- **Строки «Российская Федерация» в файле выпуска нет** (только округа и области),
  поэтому сравнение — с Приволжским ФО.
- Прогон месячный (`job_penza` + метка `checked` в `penza_meta`), но сид сверяет
  число ключей с `penza_expected_keys()` (81 ряд), чтобы новый сюжет не дожидался
  суток.

API: `GET /api/penza` — ряды + `meta` с именами файлов, чтобы любую цифру можно
было открыть у первоисточника.

## Кривая ОФЗ и родословная корзины

`OFZ_UNIVERSE` в `backend/econ.py` — список из 13 выпусков ОФЗ-ПД с погашением
2027–2041. Состав **не пересобирается автоматически**: пересборка по обороту дня
меняла бы сам ряд, и «как менялись доходности» стала бы несравнимой. Правила
отбора и снятые с борта цифры — в раскрывающемся блоке на вкладке.

Выход выпуска из корзины описан в `OFZ_LINEAGE`:

```python
OFZ_LINEAGE = {"SU26207RMFS9": {"exit": "2027-02-03", "replaced_by": "SU26232RMFS7"}}
```

`GET /api/econ/bonds` размечает это так:

- пока выпуск торгуется (`exit_date` в будущем или делистинг ещё не прошёл) —
  строка обычная, с `exit_date`, `replaced_by` и подписью на фронте «выйдет
  ДД.ММ.ГГГГ»;
- **вывод = отсутствие выпуска в сегодняшнем снимке**, а не дата в календаре:
  биржа держит бумагу на бортах несколько дней после погашения, и серить строку
  по дате было бы враньем;
- когда выпуск исчез с борта, эндпоинт подставляет его **последнюю реальную
  запись** с `retired: true` и `snap_date` этой записи; если записей нет (вывод
  случился до начала наблюдений) — строка не появляется, выдумывать нечего;
- выведенные строки участвуют в графике (сравнить «как было» можно), но не
  участвуют в наклоне кривой и в счётчике корзины; цвет им — серый, не из палитры.

Порядок действий при погашении: заранее добавить преемника в `OFZ_UNIVERSE`
(история подтянется `fetch_ofz_history`), записать пару в `OFZ_LINEAGE`, после
делистинга сам выпуск из корзины убрать — строка останется.

## Блок «Металлопрокат»

Одно слово, два разных ряда — поэтому таблицы лежат отдельно и не смешиваются.

| Ряд | Источник | Что это |
|---|---|---|
| `pr_*` | Росстат, «Средние цены производителей на отдельные виды промышленных товаров (с 1998 г.)» | цена завода за тонну, без НДС, по РФ, ежемесячно, лаг ~2 месяца |
| `dk_*` | мониторинг журнала «Металлоснабжение и сбыт» (metalinfo.ru) | опрос металлотрейдеров Центрального региона (Москва), ₽/т, шаг ~2 недели |

9 позиций Росстата (чугун, слиток, лист г/к и х/к, сортовой, балка, трубы э/с и
ВГП, проволока) и 18 дилерских сортопозиций + сводный ряд `dk_index` (среднее по
позициям, считаем сами).

Нюансы, которые надо знать при правке:

- **Имя файла Росстата живёт один месяц** (`Proizvoditeli_Cena_09-2026.xlsx`,
  соседние месяцы — 404), поэтому сначала парсим страницу `statistics/price` и
  берём максимальный `MM-YYYY`, и только потом качаем 2,5 МБ. Если страница
  недоступна — перебор шаблонов за 8 месяцев, как с квартальными `urov_12kv_*`.
- **Разметка листов не одинакова**: 2021–2023 — значения в самой строке товара,
  2024–2025 — строкой ниже («Российская Федерация»), 2026 — то же, но добавлена
  колонка «Единицы измерения» и месяцы сдвигаются. Колонки ищем по подписям,
  строку РФ — по началу строки; листы 1–3 (1998–2020) пропускаем: там годовые
  средние, в месячный ряд их класть нельзя.
- **Арматуры в Росстате нет** — группировка 24.10.61 по РФ закрыта прочерками
  «…». Она есть только в дилерском мониторинге, поэтому нижняя таблица нужна.
- **МСиБ за WAF**: запросы без браузерных заголовков получают 403, а после
  серии запросов бан прилетает по IP (ловили при отладке). Отсюда два тормоза:
  ходим на сайт не чаще раза в сутки (`dealer_attempt` в `prokat_meta`) и только
  если последнее наблюдение старше `MSIB_MIN_AGE_DAYS` (10 дней). Даты берём из
  `setLabels([...])` на странице, ряды — из ajax-эндпоинта `/statistics/data?`;
  если длин не совпало, ряд не пишем вовсе (иначе точки уедут по датам).
  Когда мониторинг недоступен, на фронте — честная заглушка «нет данных», а не
  нули.
- **Числа-строки**: `_rub_number()` разбирает «53750.000», «62 900,5»,
  «1.234,5» и режет выноски «103,4 2)»; «…» и «…» это отсутствие данных.

API: `GET /api/prokat` (ряды + `meta` с именем файла и датами наблюдений).
Ряды зарегистрированы в `ECON_SERIES` с группой `prokat`, так что их описывает и
`GET /api/econ/meta`.

## Блок «Экономика» (econ.py)

Шесть срезов, которые отвечают на «что вообще происходит в стране», а не только
в курсах:

| Срез | Источник | Как часто |
|---|---|---|
| Ставки по кредитам (бизнес до/свыше года, люди, авто) и вкладам (люди/юрлица) | XLSX ЦБ `cbr.ru/vfs/statistics/pdko/int_rat/{loans_nonfin,loans_ind_new,deposits}.xlsx`, лист `ставка_руб` | ~7–10 числа за прошлый месяц (лаг ~2 мес) |
| Средние ставки топ-10 банков по вкладам (по бакетам сроков) | `regulatory_rates.xlsx`, лист «в рублях» | ежемесячно |
| Кривая ОФЗ (12 ликвидных выпусков 2027–2041): доходность, цена в % от номинала, изменение за день, НКД, оборот; плюс дата выпуска, купон и объём выпуска из `/iss/securities/<ISIN>/issue.json` | ММВБ ISS, борт `TQOB`: `marketdata.YIELD`/`LAST`, `securities.MATDATE`/`ACCRUEDINT`, история `YIELDCLOSE` (страницами по 100) | каждые 12 часов; справочник выпуска — раз в месяц |
| Промпроизводство, безработица, номинальная зарплата | Росстат SDDS: `SDDS_industrial_production_index.xlsx`, `SDDS_labor_market.xlsx` | ежемесячно |
| Реальные располагаемые доходы (квартал) | Росстат, ротационное имя `urov_12kv_<q>kv<год>.xlsx` (подбирается перебором) | ежемесячно |
| Оборот розницы и исполнение федерального бюджета | вручную: POST `/api/econ/real`, POST `/api/budget` | по публикации данных |

Почему последние два ручные: **Минфин отдаёт 403/503 всем не-браузерным
запросам** (проверено и с локальной машины, и с VPS), а выгрузки Росстата по
рознице каждый месяц переименовываются и старые ссылки не выдаёт поиск сайта.
Формат и загрузка — `backend/update_budget.py` (mlрд ₽, накоплено с начала
года); секрет тот же `TOP_BANKS_SECRET`, что у рейтинга банков.

Нюансы TLS: у rosstat.gov.ru цепочка от «Russian Trusted CA» — для него
отключена проверка сертификата (`INSECURE_HOSTS`), к остальным источникам
проверка применяется как обычно.

## Как запустить локально

```bash
# терминал 1 — бэкенд (порт 5002)
cd backend
pip3 install -r requirements.txt
python3 app.py

# терминал 2 — фронтенд (порт 5174, проксирует /api на 5002)
cd frontend
npm install && npm run dev
```

Открыть http://localhost:5174

```bash
cd backend

```

Сеть в тестах подмешивается (mock), поэтому они не зависят от биржи.

## Продакшен (Timeweb VPS)

```bash
docker compose up -d --build
# сайт: http://<IP>:8080
```

Ключевые настройки бэкенда (переменные окружения контейнера):

| Переменная | Что делает |
|---|---|
| `DATABASE_FILE` | путь к SQLite (в compose — том `/data/rates.db`) |
| `MOEX_FORCE_HTTP` | `1` — ходить в ISS по http вместо https (на VPS MOEX отдаёт цепочку с «Russian Trusted Sub CA», которой нет в стандартном доверилище, и TLS-рукопожатие падает; локально флаг не нужен) |
| `TOP_BANKS_SECRET` | включает POST /api/top-banks (обновление рейтинга банков); без неё — 503 |
| `SKIP_SCHEDULER` / `SKIP_SEED` | не поднимать планировщик / не лезть в сеть при старте (тесты) |

### Обновление рейтинга банков

Живого открытого API указателя ЦБ нет, поэтому рейтинг лежит в базе и
обновляется вручную (раз в квартал, после выхода указателя):

```bash
# banks.json: {"as_of": "01.12.2026", "banks": [{"name": "Сбербанк", "assets": 63.9,
#              "n1": 13.5, "profit": 1730, "siber": true,
#              "cap123": 6.6, "vkl_fiz": 28.3, "sred_org": 23.1,
#              "grp": "top"|"extra", "place": 13}, ...]}
# rank проставляется сам по порядку внутри группы; grp по умолчанию 'top';
# cap123/vkl_fiz/sred_org — трлн ₽, assets/profit — тоже необязательные
# (ПСБ не публикует форму 0409101 → прочерк).
TOP_BANKS_SECRET=<секрет> TOP_BANKS_URL=http://<IP>:8080 \
    python3 backend/update_top_banks.py banks.json
```

Если обновить срез нужно сразу после апгрейда схемы (старая таблица не
умеет NULL в assets/profit, а семя app.py перезаписывает таблицу только
когда она пуста) — пересоздать её и заправить семя можно вот так:

```bash
docker stop moex-rates-backend-1
docker cp moex-rates-backend-1:/data/rates.db /tmp/rates.db
python3 backend/reseed_top_banks.py /tmp/rates.db backend/app.py
docker cp /tmp/rates.db moex-rates-backend-1:/data/rates.db
docker start moex-rates-backend-1
```

Без заданного `TOP_BANKS_SECRET` эндпоинт отвечает 503 — на проде секрет
задаётся в окружении контейнера backend.
