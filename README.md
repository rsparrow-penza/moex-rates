# 📊 MOEX Rates — курсы USD, EUR и CNY с Московской биржи

Второй учебный проект: сервис, который **сам, раз в час**, читает курсы валют
с публичного API ММВБ (ISS), сохраняет их в базу SQLite, а веб-страница
показывает историю с выбором диапазона дат и графиком.

## Стек

| Слой | Технологии |
|---|---|
| Планировщик + API | Python 3, Flask, APScheduler, requests |
| База данных | SQLite (том Docker, дубли дат исключает PRIMARY KEY) |
| Фронтенд | React 19 + Vite, график — чистый SVG без библиотек |
| Упаковка | Docker Compose (nginx + gunicorn) |

## Источники данных (это интересная часть)

- **USD**: `USDFIXME` — валютный фиксинг МосБиржи. Биржевые спот-торги
  долларом приостановлены, поэтому берём биржевой фиксинг; он обновляется
  раз в сутки (~13:00 МСК).
- **USD·OTC**: Yahoo Finance (`RUB=X`) — **внебиржевой межбанковский курс**,
  он же в приложении «Акции» на iPhone. Обновляется круглосуточно;
  забирается внутридневной ряд с шагом ~15 минут за последние сутки.
  ⚠️ Неофициальный API: может измениться или исчезнуть — поэтому это
  второй источник, а не замена ММВБ.
- **EUR**: `EURFIXME` — то же для евро: фиксинг МосБиржи, раз в сутки.
- **EUR·OTC**: Yahoo Finance (`EURRUB=X`) — межбанк по евро, те же сутки
  с шагом ~15 минут.
- **CNY**: `CNYRUB_TOM` — полноценные спот-торги юань/рубль, цена
  обновляется весь торговый день (10:00–23:50 МСК).
- **USD/EUR/CNY ·ЦБ**: официальный курс ЦБ РФ прямо с cbr.ru
  (`XML_daily.asp`): один XML на все валюты сразу, кодировка windows-1251,
  даты «дд.мм.гггг», разделитель-запятая в числе. Работает и для выходных.

У каждой записи в базе есть `source` (MOEX/YAHOO/CBR) и `rate_time` —
внутридневные точки OTC живут рядом с дневными, не мешая им.

График умеет два режима (переключатель **% / ₽**):
- **%** — изменение каждой валюты от начала периода на общей шкале:
  ряды 12/81/90 ₽ сравнимы, видно, кто за период сильнее вырос или упал.
  Пунктир — официальные курсы ЦБ, сплошные линии — биржа и OTC.
- **₽** — абсолютные цены: у каждой валюты своя мини-полоска со своей
  шкалой (приём «small multiples»), чтобы юань не сплющивало у нуля.

Абсолютные значения — и в таблице: ММВБ и ЦБ стоят бок о бок, есть
что сравнить (OTC в таблицу не попадает — сутки 15-минуток раздули бы её).

Плюс «backfill»: при первом запуске подтягивается история за ~90 дней,
чтобы таблица сразу была не пустой.

## Как запустить локально

```bash
# терминал 1 — бэкенд (порт 5002)
cd backend
pip3 install -r requirements.txt
python3 app.py

# терминал 2 — фронтенд (порт 5174, проксирует /api на 5002)
cd frontend
npm install && npm run dev
```

Открыть http://localhost:5174

## Тесты

```bash
cd backend
python3 -m unittest discover -v
```

Сеть в тестах подмешивается (mock), поэтому они не зависят от биржи.

## Продакшен (Timeweb VPS)

```bash
docker compose up -d --build
# сайт: http://<IP>:8080
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/rates?from=2026-10-01&to=2026-11-01&currencies=USD,CNY` | курсы за период |
| GET | `/api/currencies` | список валют со справочными названиями |
| GET | `/api/health` | число записей и время последнего обновления |
