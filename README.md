# 📊 MOEX Rates — курсы USD и CNY с Московской биржи

Второй учебный проект: сервис, который **сам, раз в час**, читает курсы валют
с публичного API ММВБ (ISS), сохраняет их в базу SQLite, а веб-страница
показывает историю с выбором диапазона дат и графиком.

## Стек

| Слой | Технологии |
|---|---|
| Планировщик + API | Python 3, Flask, APScheduler, requests |
| База данных | SQLite (том Docker, дубли дат исключает PRIMARY KEY) |
| Фронтенд | React 19 + Vite, график — чистый SVG без библиотек |
| Упаковка | Docker Compose (nginx + gunicorn) |

## Источники данных (это интересная часть)

- **USD**: `USDFIXME` — валютный фиксинг МосБиржи. Биржевые спот-торги
  долларом приостановлены, поэтому берём биржевой фиксинг; он обновляется
  раз в сутки (~13:00 МСК).
- **CNY**: `CNY000000TOD` — полноценные спот-торги юань/рубль, цена
  обновляется весь торговый день (10:00–23:50 МСК).

Плюс «backfill»: при первом запуске подтягивается история за ~60 дней,
чтобы таблица сразу была не пустой.

## Как запустить локально

```bash
# терминал 1 — бэкенд (порт 5002)
cd backend
pip3 install -r requirements.txt
python3 app.py

# терминал 2 — фронтенд (порт 5174, проксирует /api на 5002)
cd frontend
npm install && npm run dev
```

Открыть http://localhost:5174

## Тесты

```bash
cd backend
python3 -m unittest discover -v
```

Сеть в тестах подмешивается (mock), поэтому они не зависят от биржи.

## Продакшен (Timeweb VPS)

```bash
docker compose up -d --build
# сайт: http://<IP>:8080
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/rates?from=2026-10-01&to=2026-11-01&currencies=USD,CNY` | курсы за период |
| GET | `/api/currencies` | список валют со справочными названиями |
| GET | `/api/health` | число записей и время последнего обновления |
